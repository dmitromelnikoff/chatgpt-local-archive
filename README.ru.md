# ChatGPT Local Archive

**Локальный просмотрщик и инструмент восстановления файлов официального экспорта ChatGPT.**

**Зафиксированная версия:** `7.3.16.1`. **Автор:** [Dmitro Melnikov](https://github.com/dmitromelnikoff). [README in English](README.md).

Это действующая разработка, созданная последовательными итерациями и проверенная пользователем на личном архиве. Репозиторий содержит **исходный код программы**, но не должен содержать исходные личные переписки или восстановленные вручную вложения.

## Задача

Экспорт ChatGPT состоит из JSON-графов сообщений, раздельных манифестов файлов и иногда неполных вложений. Программа конвертирует его в автономные HTML-страницы, связывает доступные вложения с переписками, отмечает сомнительные соответствия и позволяет вручную восстановить отсутствующие файлы.

## Реализованные возможности

- Потоковая обработка `conversations-*.json`, список и поиск по чатам, виртуальная прокрутка.
- Календарь по годам и месяцам **последнего обновления** переписки, общая статистика.
- Счётчики пользовательских вопросов и уникальных доступных изображений, настоящий признак `archived` при наличии в экспорте.
- Галерея, полный перечень выходных файлов, отчёты об идентификации и восстановление отсутствующих файлов через локальный сервер.
- Навигация QUESTIONS, копирование вопроса, ответа, кода и всего чата; экспорт в `.md` с именем по заголовку; ссылка на оригинальную переписку.
- Markdown, таблицы, формулы MathJax и **частичный** рендеринг Intelligent UI/DIL с альтернативным режимом чтения.
- Предохранитель от случайной повторной конвертации поверх восстановленного архива.

**Внимание:** сложный DIL воспроизводится приблизительно, а часть связей файлов восстанавливается эвристически, с обозначением неопределённости.

## Установка и запуск

Требуется **Python 3.9+**. Все необходимые библиотеки включены в состав поставки; `pip install` не нужен.

1. Скачайте/клонируйте репозиторий.
2. Распакуйте **свой официальный экспорт OpenAI** в ту же папку, где находится `build_from_export.py`. Файлы `conversations-000.json`, остальные JSON-шарды и доступные `file_*.dat` должны находиться рядом со скриптами.
3. Windows: `01_BUILD_ARCHIVE.bat` → `02_OPEN_ARCHIVE.bat`.
4. Linux/macOS: `sh build_archive.sh` → `sh open_archive.sh`.
5. Работайте с адресом `http://127.0.0.1:...`, который напечатает сервер. **Не открывайте индекс через `file://`.**

В уже готовом архиве используйте `10_REFRESH_INTERFACE.bat` вместо повторной полной сборки. Перед обновлениями создавайте копии `ChatGPT_Local_Archive/`, `ChatGPT_Generated_Files/` и `recovered_files.json`.

## Структура и технологии

Программа намеренно сохраняет исходную файловую архитектуру в корне: `chatgpt_local_archive.py` (конвертер), `serve_archive.py` (локальный сервер), `archive_recovery.py` (восстановление), `archive_chat_exports.py` (метаданные и Markdown), JavaScript/CSS компонентов интерфейса, `vendor/mistune/`, `viewer/` (MathJax). Подробности — в [System Architecture](docs/ARCHITECTURE.md).

Используются Python standard library, JavaScript, HTML/CSS, Mistune и MathJax. Лицензии внешних библиотек сохранены. **Лицензия авторского кода проекта пока не выбрана** и будет добавлена только после согласования.

## Проверки и ограничения

```bash
python3 -m unittest discover -s tests -v
python3 check_package.py
```

Синтетические тесты не содержат личных переписок. Подтверждение работы реального архива относится к последовательно установленной версии `v7.3.16.1`, а не означает проверку каждого возможного экспорта. Точная совместимость с закрытым Intelligent UI OpenAI не заявляется.

## Конфиденциальность

**Не публикуйте** `conversations*.json`, файлы медиа, `ChatGPT_Local_Archive/`, `ChatGPT_Generated_Files/`, реестры ручного восстановления и другие личные данные. `.gitignore` защищает от случайного добавления типичных файлов, но не заменяет проверку `git status` и `git diff --cached`.
