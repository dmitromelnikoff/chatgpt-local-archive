ChatGPT Local Archive — STABLE v7.3.16.1 (2026-10-12)
========================================================
Единый полный автономный Python-пакет для чистого развертывания.
Не устанавливайте промежуточные ZIP-патчи поверх него.

Объединено:
- основа STABLE v7.3.14: потоковая конвертация, Gallery, Files ChatGPT,
  восстановление, Library bindings, synthesized, навигация QUESTIONS,
  копирование ответов, переключатели Service JSON / Intelligent UI,
  Markdown и автономный MathJax;
- v7.3.15: календарь и статистика в главном списке;
- v7.3.16: копирование вопросов, кода, целого чата, .md, ссылка на оригинал,
  счетчики вопросов и изображений, статус archived;
- v7.3.16.1: сервер правильно выдает JS списка метаданных,
  файл Markdown скачивается с именем по заголовку чата.

Новый архив: 01_BUILD_ARCHIVE.bat -> 02_OPEN_ARCHIVE.bat.
Существующий архив: 10_REFRESH_INTERFACE.bat (без повторной конвертации).

Известные ограничения: Intelligent UI воспроизводится частично, отдельные
Markdown-звездочки в DIL остаются; физически отсутствующие файлы не создаются.

Сохраняйте ChatGPT_Local_Archive/, ChatGPT_Generated_Files/, оригинальный экспорт.
Пакет не содержит личных переписок, изображений или других данных пользователя.
