- Свежий каталог с одним экспортированным чатом, настоящим PNG в `.dat`, одной отсутствующей записью Library и веткой `user → reasoning_recap → assistant/text`.
- Запуск `build_from_export.py` завершился с кодом 0. Сформированы индекс, чаты, assets, Gallery, отчёты.
- Главная страница содержит **ровно одно** подключение Chat Actions, подключения календаря и статистики; файлы JS/CSS присутствуют.
- Индекс `chat_metadata_index.json`: 2 вопроса, `is_archived=true`, 1 уникальное изображение, исходный Markdown готов.
- Markdown содержит формулу `$$E=mc^2$$` и код, не содержит `reasoning_recap`.
- Повторный `build_from_export.py` отказал с кодом 3: защита существующего архива.
- `refresh_ui_only.py` повторно подключил функции и перестроил индекс **без дублирования** скриптов.
- HTTP-сервер по localhost + случайному токену выдал index, календарь JS/CSS, метаданные, кнопки копирования, целевой HTML-чата, JS с Markdown, сам `.md`.
- Заголовок Content-Disposition скачиваемого `.md` содержит **имя чата на кириллице** в RFC 5987.
- HTTP API «Файлы ChatGPT» сообщил отсутствующий PNG; последующая загрузка настоящих PNG-байт успешно создала asset, файл в Recovered_From_Browser и запись в `recovered_files.json`, сохранив связь с чатом.
- В первом тесте отсутствия ресурса проверка не подменяет случайным файлом: требуется точный размер Library и разрешённая сигнатура содержимого.
