# Проверки зафиксированного релиза

Проверялся комплект, **собранный из всех финальных файлов версий**, а не последовательность старых ZIP-исправлений. Для итогового релиза подготовлен отдельный скрипт `build_from_export.py`.

## Сквозные проверки на синтетическом экспорте

- Минимальный официальный формат `conversations-000.json` с `mapping`/`parent`, несколькими пользовательскими и ассистентскими узлами.
- `library_files.json` с физическим `file_ID.dat` (PNG) и вторым PNG, **отсутствующим физически**.
- Виртуальный `origination_message_id`, совпадающий с `metadata.parent_id` служебного сообщения. Изображение привязано к потомку `assistant/text` с меткой `inferred`.
- Автоматическое создание HTML, CSV-отчётов, папок `assets`, `dil_sources`, копирование MathJax.
- Автоматическое изменение ссылки вкладки «Файлы ChatGPT» без удаления исходного полного `generated_files.html`.
- Проверка путей изображений, вывод отчёта `image_paths_summary.txt`.
- Локальный HTTP-сервер: открытие `index.html`, чата, API полного списка, а также доставка `copy_answers.js`, `question_navigation.js`, `structured_blocks_toggle.js`, `intelligent_ui_toggle.js`.
- Отсутствующий PNG успешно загружен через `POST /__recovery/api/upload/ID` под локальным URL; в `recovered_files.json` записаны ID, имя, размер и SHA-256. Бинарный файл помещён в `ChatGPT_Generated_Files/Recovered_From_Browser`, а копия — в `assets`.
- Исходные упоминания `![Отсутствующий плакат]` и `[Скачать PNG]` заменены рабочим изображением и ссылкой внутри содержимого ассистента, без третьей CSS-колонки.
- Сохранена резервная копия HTML до восстановления; повторное применение реестра не должно создавать дубли.
- Базовая поддержка DIL и формул: исходный UI сохраняется в `dil_sources`, локальный MathJax включается в страницу.

## Отдельно проверявшиеся функции в ходе разработки

В предыдущих версиях в Chromium проверялись: навигация QUESTIONS с 17 запросами из диагностического чата, кнопка копирования в изолированном iframe, общий переключатель служебных JSON, двухрежимное отображение D12 с таблицами и математикой, корректность загрузки настоящих PNG через HTTP и восстановление ссылок на несколько файлов в одном ответе.

Точное содержимое всех 19 исходных шардов и всех физических ассетов пользователя **не было локально загружено в эту тестовую среду**, поэтому тесты не заменяют проверку после установки на его компьютере.

## Проверка после установки на полном экспорте

1. Проверить завершение `01_BUILD_ARCHIVE.bat`, открыть `build_log.txt` и число чатов.
2. Открыть через `02_OPEN_ARCHIVE.bat` любой чат-генератор и галерею; убедиться, что изображения есть в обоих местах.
3. В «Файлы ChatGPT» убедиться, что показан **полный** список, у отсутствующих — кнопки восстановления.
4. Проверить восстановление одного PNG и соответствующую исходную ссылку в сообщении.
5. Открыть чат «[обезличенный диагностический чат]»: панель QUESTIONS ожидаемо содержит 17 пользовательских промптов для этой версии истории.
6. Проверить кнопки «Скопировать ответ», переключатели «Служебные блоки» и «Intelligent UI».
7. Открыть D12: Markdown OFF должен сохранять текст, таблицы и формулы по порядку; исходный DIL доступен отдельным файлом. Декоративные SVG в Markdown могут отображаться как текст.
8. Запустить `03_VERIFY_IMAGES.bat` и проверить различия между «сломаны пути HTML» и «файл не попал в переписку».
9. Закрыть сервер и снова открыть `02_OPEN_ARCHIVE.bat`; реестр восстановленных файлов должен сохраниться.

## Если возникла ошибка

Пришлите **точный текст ошибки, название чат-страницы, `image_paths_summary.txt` и несколько нужных строк соответствующего CSV**, предварительно убрав личные данные. Не требуется пересылать весь архив или ключ локального HTTP-сервера.
