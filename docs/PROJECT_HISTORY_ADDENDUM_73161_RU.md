# Итоговая история: v7.3.15 → STABLE v7.3.16.1

Этот документ дополняет `PROJECT_HISTORY_RU.md`, где разобраны все предыдущие этапы от раннего конвертера до v7.3.14.

## Зафиксированные результаты до v7.3.14

Самым значимым открытием стал виртуальный `Library.origination_message_id`: он часто совпадает с `message.metadata.parent_id` служебного узла, а не с ID видимого ответа. По ветке `mapping.parent` восстанавливаются многие связи с ответом. Для генераций без видимого ответа применяется отдельная синтетическая карточка у соответствующего запроса (с указанием предположительности), а сомнительные файлы остаются в общей сводке. Ручная загрузка отсутствующих файлов работает через localhost, реестр и строгое соответствие Library, исходным Markdown-ссылкам и восстанавливаемому сообщению. Full Files ChatGPT list не заменяется урезанной копией. Два режима UI используют один реестр восстановлений.

## v7.3.15 — Календарь и статистика

После сравнения с другим просмотрщиком выбран не вариант постоянной третьей колонки, а кнопки «Даты» и «Статистика» над списком чатов слева. Календарь выбирает год и месяц по **дате последнего обновления переписки**, фильтр месяца сочетается с поиском. Статистика доступна в основной области, но возврат к переписке не требует её перезагрузки. Статусы уже вручную восстановленных файлов рассчитываются на основе фактического состояния, а не только старого CSV. Проверка проведена на индексе масштаба 1 813 чатов.

## v7.3.16 — Копирование и сведения о чатах

Добавлены действия по отдельным элементам: кнопка копирования вопроса справа внизу пользовательского сообщения, кнопка копирования настоящих блоков кода справа вверху (без Markdown-ограждений). Служебные DIL `pre/code` нельзя ошибочно считать программным кодом.

В панель под заголовком справа от переключателей добавлены три действия: копирование чата, скачивание Markdown и открытие исходной беседы по реальному UUID. Для копирования и скачивания используется **одна подготовленная Markdown-версия из исходной основной ветви JSON**, а не текущий DOM. Служебные `thoughts`/`reasoning_recap` и сообщения инструментов исключены. Вложенные изображения сохраняют доступные ссылки, включая подтверждённые восстановления. В левом списке под названием добавлены счётчики пользовательских вопросов, уникальных изображений и `archived` по реальному атрибуту источника. Поиск/календарь и виртуальный список остаются прежними.

## v7.3.16.1 — Исправление реального внедрения

Пользователь сообщил, что атрибуты чатов не отображаются: браузер получал 404 на `archive_chat_list_meta.js`. Причина — скрипт лежал рядом с сервером, а запрашивался относительно архива. Добавлен явный серверный маршрут, возвращающий скрипт. Также исправлено имя скачиваемого Markdown: вместо `chat_0001795_....md` используется название беседы с исключением запрещённых Windows-символов. Пользователь проверил **на своей системе, что оба исправления и все остальные функции работают**, после чего v7.3.16.1 утверждена как стабильная точка.

## Единая поставка STABLE v7.3.16.1

Ранее v7.3.15, v7.3.16 и v7.3.16.1 были последовательными аддонами. В единой поставке их код и все зависимости включены в корень ZIP. Стандартная `01_BUILD_ARCHIVE.bat` после конвертации сама устанавливает восстановление, календарь, статистику, метаданные и Markdown. Для уже готового архива есть `10_REFRESH_INTERFACE.bat`.

Версия фиксируется как практический локальный архив, **не как точный исходный ChatGPT Intelligent UI**. Дальнейший полноценный DIL-движок — отдельная экспериментальная работа, которая не должна ломать текущий код и пользовательские файлы.
