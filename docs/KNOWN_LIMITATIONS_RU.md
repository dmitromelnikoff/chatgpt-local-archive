# Известные ограничения замороженной версии v7.3.14

1. **Intelligent UI/DIL неполон.** Визуализация приближенная; ряд динамических/интерактивных элементов не работает. Некоторые UI-подписи по-прежнему содержат буквальные `**...**`. Это сознательно оставлено для будущей системной переработки DIL-парсера. Не менять здесь случайные CSS или JavaScript-регулярные выражения.
2. **Markdown OFF — режим чтения, не оригинальный ChatGPT UI.** SVG превращается в подписи, ряд декоративных блоков — в текст. При сложных конструкциях может понадобиться полный исходник DIL.
3. **Не все Library-записи физически присутствуют в экспорте.** Никакая программа не сможет восстановить отсутствующие байты без вашей личной копии файла. Статус `created` — не доказательство наличия локального файла.
4. **Точность эвристических привязок не абсолютная.** Временные правила и синтетические карточки могут потребовать ручной проверки, особенно в чатах с несколькими ветками. `inferred` ≠ `exact`.
5. **Одинаковые имена не означают одинаковые файлы.** При коллизии программа скорее оставит неопределённость, чем заменит один документ другим.
6. **Восстановление по исходной подписи** наиболее надёжно при наличии оригинальных `conversations-*.json`. Если исходный JSON удалён, неоднозначные подписи не всегда можно восстановить автоматически.
7. **`copy_answers.js`** переносит структуру и Markdown-подобный текст, но не копирует бинарное содержимое PNG и не гарантирует идеальное соответствие копированию на сайте ChatGPT.
8. **Новые серверные/динамические элементы** (`AsyncImage`, поисковые ответы, Actions и внешние запросы) могут требовать данных, которых офлайн-экспорт не содержит.
9. **Пользовательские HTML/SVG в assets** могут ссылаться на свои внешние файлы. Эти ссылки могут оставаться ошибочными; к HTML собственно чатов это может не относиться.
10. **Полному экспорту конкретного пользователя локально в этой среде не подвергали испытания.** Проверялись сокращённые диагностические JSON, синтетические полные экспорты, отдельные реальные HTML, отчёты, поведение Chromium и пользовательские проверки на Windows. Размер архива более 1 ГБ требует дополнительной проверки на его реальной машине.
11. **Сборка поверх восстановленного архива защищена от случайного запуска.** Если намеренно пересобрать его командой `--rebuild-after-backup`, HTML и некоторые отчёты могут быть перезаписаны; старые ручные изменения нельзя считать автоматически перенесёнными.
12. **Локальная безопасность.** Сервер слушает только `127.0.0.1` и использует непредсказуемый ключ в URL. Не раздавайте ключ и не открывайте произвольные экспортированные `.html/.svg` как доверенные исполняемые приложения. Не размещайте каталог экспорта на общем веб-сервере без дополнительной защиты.

## Известная проблема «звёздочки»

Если конкретная надпись UI выглядит как `**EXAMPLE LABEL**` или `**Example UI Label**`, это **не утрата текста или данных**, а сбой смешанной Markdown/DIL-разметки. В v7.3.14 исправлены известные структуры, но не каждый возможный `codeblock`. Пользователь согласовал фиксацию этого дефекта ради сохранности остальных механизмов.

## Отчётность вместо умолчаний

Прежде чем считать архив полным, проверьте: число чатов в `conversations_index.csv`, строки с `status=ERROR`, `unplaced_library_files.csv`, результаты `library_integrity_report.csv`, физический `assets/` и `image_paths_summary.txt`. Наличие красивой галереи само по себе не доказывает, что весь экспорт перенесён.
