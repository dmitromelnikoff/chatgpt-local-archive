# ChatGPT Local Archive — STABLE v7.3.16.1

**Дата фиксации:** 12 октября 2026 года. **Назначение:** локальный автономный просмотр официального экспорта ChatGPT, включая сообщения, изображения, файлы Library, формулы, частично поддерживаемый Intelligent UI, навигацию и восстановление отсутствующих файлов.

Это **единый полный исходный и установочный пакет**, а не очередной патч. Он объединяет рабочую основу v7.3.14 с календарём/статистикой v7.3.15, действиями чата v7.3.16 и проверенным пользователем исправлением v7.3.16.1.

## Быстрый старт — новый архив в Windows

1. Установите **Python 3.9 или новее** и включите доступность Python из командной строки. Сторонние Python-пакеты через pip **не нужны**: Mistune и MathJax входят в поставку.
2. Распакуйте официальный экспорт ChatGPT в отдельную папку, например `D:\ChatGPT_Export`. Должны присутствовать `conversations-000.json` и прочие части; возможно `library_files.json`, `conversation_asset_file_names.json`, много файлов `file_....dat` и другие оригинальные материалы.
3. Распакуйте **все файлы этого ZIP непосредственно в ту же папку**. Рядом с `conversations-000.json` должны лежать `build_from_export.py`, `serve_archive.py` и `01_BUILD_ARCHIVE.bat`.
4. Запустите **`01_BUILD_ARCHIVE.bat`**. Это однократная конвертация. На экспорте более 1 ГБ процесс может быть длительным. По завершении календарь, статистика, атрибуты и Markdown будут включены **автоматически** — отдельные старые установщики не нужны.
5. Запустите **`02_OPEN_ARCHIVE.bat`**. Откроется браузер по локальному адресу `http://127.0.0.1:...`. Оставьте окно сервера открытым на время просмотра.

**ВАЖНО:** открывайте архив через BAT/локальный сервер, **не через `file://`**, иначе часть картинок и скриптов может не отображаться.

## Уже есть рабочая v7.3.16.1?

**Не переустанавливайте её ради установки.** Сохраните эту ZIP-сборку отдельно как резервный полный дистрибутив, а действующую программу и восстановленные файлы — как резервную копию. Это снимок кода v7.3.16.1, собранный и проверенный на тестовом экспорте; он не содержит ваших личных данных.

Если всё же потребуется подключить новые интерфейсные функции к **уже конвертированному** архиву после установки полного пакета, используйте **`10_REFRESH_INTERFACE.bat`**, а не `01_BUILD_ARCHIVE.bat`. Команда обновляет только главный индекс, календарь/статистику и производные метаданные/Markdown; не пересоздаёт HTML переписок и не удаляет восстановленные файлы. Для пересоздания индекса нужны исходные `conversations-*.json`.

## Работающие функции

- Поиск и виртуальный список переписок; **календарь по году/месяцу** и **общая статистика**. Календарь использует дату последнего обновления чата, а не дату каждого сообщения.
- Под названиями слева: дата/время, число пользовательских вопросов, число уникальных доступных изображений, отметка `archived` **только** по достоверному признаку оригинального JSON.
- Просмотр основных ответов, вложений, галереи, файлов, Markdown, таблиц, кода, формул MathJax и части DIL/Intelligent UI.
- Правая навигация QUESTIONS: переход к промпту и подсветка активного.
- Переключатель **«Служебные блоки»**: по умолчанию скрывает служебный JSON.
- Переключатель **«Intelligent UI»**: визуализация или альтернативный читаемый Markdown. Формулы вне UI не меняются.
- «Скопировать ответ», иконка копирования вопроса и кнопка копирования настоящих блоков кода.
- Справа от переключателей: **скопировать весь чат**, **сохранить `.md` с именем по заголовку чата**, **открыть исходную переписку на ChatGPT**, если оригинальный ID доступен.
- При копировании/сохранении чата используется единый подготовленный Markdown из основной ветки оригинального JSON; `thoughts`, `reasoning_recap`, сообщения инструментов исключаются. Отображаемое состояние переключателей не влияет на копию.
- Полная исходная вкладка «Файлы ChatGPT» и кнопки **«Восстановить»** напротив недостающих элементов; успешно восстановленные изображения возвращаются в соответствующие HTML-чаты, если место определено.
- Отчёты привязок: прямые, восстановленные через промежуточные ID, синтетические карточки и `unplaced` для неопределённых случаев.

## Защита данных и резервные копии

- Исходные JSON и `.dat` не изменяются конвертером.
- Повторный запуск `01_BUILD_ARCHIVE.bat` **отказывается** перезаписывать уже существующий архив. Не используйте `--rebuild-after-backup` без полного резервного копирования.
- Перед любыми обновлениями сохраняйте **обе папки** `ChatGPT_Local_Archive/` и `ChatGPT_Generated_Files/`, включая `recovered_files.json`, а также оригинальный экспорт OpenAI.
- Не удаляйте `*.html.before_recovery.html` из `ChatGPT_Local_Archive/chats/`: они нужны для корректной повторной привязки восстановленных ссылок.
- Локальный сервер слушает только `127.0.0.1` и создаёт случайный адрес с токеном на каждый запуск; он не загружает данные в интернет. Внешняя ссылка ChatGPT работает только при вашем явном нажатии.
- Скачанный `.md` использует относительные ссылки `../assets/` из внутренней папки `chat_exports/`. Если переместить `.md` в другое место, ссылки на вложения могут потребовать переноса файлов.

## Известные ограничения

1. **Intelligent UI не является нативным движком OpenAI.** Часть сложного DIL, динамических компонентов и форматирования (включая отдельные буквальные `**...**`) отображается приблизительно. Это зафиксированный косметический дефект.
2. Экспорт OpenAI иногда не содержит самих медиа или прямых ID. Конвертер не может создать отсутствующие байты; непроверенные привязки помечаются как предположительные.
3. `fallbackMarkdown` может быть неполным. Сложные компоненты Markdown-режим показывает приближённо, но исходная DIL-разметка сохраняется в архиве.
4. При отсутствии физического файла он остаётся в списке недостающих до ручного восстановления.
5. В очень длинных чатах системный буфер обмена может быть ограничен; используйте скачивание `.md`.
6. Некоторые оригинальные переписки больше недоступны на `chatgpt.com`, даже когда локальная HTML-версия существует.
